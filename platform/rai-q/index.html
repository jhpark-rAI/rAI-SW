Modeling & Model Lifecycle

SIMCA 등 분석 엔진에서 계산된 모델 Artifact를 Candidate 등록, 독립 검토, 승인 버전과 배포 근거로 연결하는 Lifecycle Governance 구조를 지원합니다.

01

Candidate Intake & Evidence

PoC에서는 rAI Pipeline, SIMCA .usp 또는 외부 모델 파일을 Candidate로 등록하고 파일 확인 정보, 성능지표와 수용 기준 Snapshot을 검토하는 흐름을 제시합니다.

  • Candidate 파일·메타데이터 등록
  • SHA-256 확인 정보
  • R²·RMSECV·MAPE 등 프로젝트 정의 지표
02

Independent Review & Signature

Modeler와 Reviewer 관점을 분리하고 변경 의도·영역, 승인·반려 Comment와 재인증 기반 서명 정보를 기록하는 검토 구조를 제시합니다.

  • Modeler / Reviewer 역할 분리
  • Approve / Reject with comment
  • 서명 의미·사용자·역할·Timestamp
03

Approved Version & Package

승인 모델을 새 버전으로 등록하고 이전 버전 상태, 버전 간 성능, 보고서와 Export Package 근거를 연결하는 개념을 보여줍니다.

  • 승인 Version Tree 및 이전 버전 상태
  • History / Model / Release Report
  • Artifact·Hash·Metadata·Signature 기록 Package
